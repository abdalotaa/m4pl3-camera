# Cámara Film

Cámara web (PWA) con looks de película analógica. La foto guardada pasa por el mismo shader WebGL que la vista previa, así que sale exactamente como se ve en pantalla.

- Looks: 800T Noche (halation roja), Fuji 400, Desechable flash
- Extras: grano, fuga de luz, fecha estampada, marco blanco o negro
- Sitio estático, sin build. Se despliega en Vercel tal cual.

En iPhone: abre la URL en Safari → Compartir → "Agregar a inicio".
